This post demonstrates the markdown features available in your content. Use it as a reference when writing.

## Text formatting

You can write **bold text**, *italic text*, and ~~strikethrough~~. Combine them for ***bold italic***.

Inline `code` uses backticks.

## Links and images

[External links](https://example.com) and [internal links](/blog) both work.

Images use standard markdown syntax:

```markdown
![Alt text](/images/photo.jpg)
```

## Lists

Unordered lists:

- First item
- Second item
  - Nested item
  - Another nested item
- Third item

Ordered lists:

1. Step one
2. Step two
3. Step three
